# 🎯 Quiz App  

A **React-based quiz application** that fetches questions from the **Open Trivia Database API** and allows users to test their knowledge interactively.  

## 🚀 Features  
- ✅ Fetches **real-time quiz questions** from an API  
- ✅ **Multiple-choice** format with correct/incorrect answers  
- ✅ **Score tracking** to display final results  
- ✅ **Smooth user experience** with React state management  

## 🛠️ Built With  
- **React (JavaScript)** ⚛️  
- **Axios** for API calls 🌐  
- **Tailwind CSS** for styling 🎨
